# Learning GO

A progressive Go learning project covering fundamental concepts and building toward practical applications.

## Prerequisites

- Go 1.16 or higher
- Basic knowledge of command-line terminal

## Project Structure

| Folder | Topic |
|--------|-------|
| 01-hello | Hello World |
| 02-variables | Variables & Data Types |
| 03-user_input | User Input |
| 04-arrays | Arrays |
| 05-slices | Slices |
| 06-Loops | Loop Structures |
| 07-ifelse | Conditionals |
| 08-strings | String Operations |
| 09-switch | Switch Statements |
| 10-functions | Functions |
| 11-packages | Packages |
| 12-Maps | Maps/Dictionaries |
| 13-Structs | Structs |
| 14-GoRoutines | Goroutines |
| 15-Channels | Channels |
| 16-server | Basic Server |
| 17-go-server | Web Server with Forms |

## Running Examples

Navigate to any project folder and run:

```bash
cd <folder-name>
go run main.go
```

Example:

```bash
cd 01-hello
go run main.go
```

## Web Server

To run the web server example:

```bash
cd 17-go-server
go run main.go
```

Then open `http://localhost:8080` in your browser.
